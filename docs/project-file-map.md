# Карта файлов проекта TORI

Этот документ описывает все файлы, которые отслеживаются Git в проекте. Он нужен
для навигации, а не заменяет комментарии в коде или журнал изменений.

## Как устроено приложение

1. Корневые PHP-файлы являются страницами и точками входа браузера.
2. `views/` содержит разметку крупных страниц, отделённую от их контроллеров.
3. `ajax/` содержит небольшие HTTP-обработчики, вызываемые JavaScript без
   перезагрузки страницы.
4. `inc/` содержит прикладные сервисы, работу с БД, безопасность и общие функции.
5. `js/` отвечает за поведение страницы в браузере, `style/main.css` — за общий
   внешний вид, `img/` — за иконки статусов и команд.
6. `sql/migrations/` — единственный источник новых изменений схемы БД. Старые
   файлы в `sql/` сохранены как совместимые ручные скрипты.

`vendor/` не описан пофайлово: это устанавливаемые Composer зависимости, не
отслеживаемые Git. Каталог `.git/` также не является частью исходного кода.

## Как безопасно менять проект

- Для нового функционала сначала ищите сервис в `inc/`, а не добавляйте SQL прямо
  в страницу или AJAX-файл.
- Новую структуру БД добавляйте только новой нумерованной миграцией в
  `sql/migrations/`; уже применённые миграции не редактируйте.
- Изменение расчётов времени сопровождайте модульным тестом, а сценарий с БД —
  интеграционным тестом в `tests/integration/`.
- Стили остаются в `style/main.css`; не добавляйте второй файл стилей без
  отдельного решения.
- После крупной видимой доработки добавляйте краткую запись в `docs/CHANGELOG.md`.
