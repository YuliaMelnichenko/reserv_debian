# Журнал значимых изменений

Здесь фиксируются только заметные для пользователей изменения, важные исправления
расчётов и изменения, требующие действий при переносе на сервер. Небольшие правки
стилей, форматирование кода и технические перестановки в журнал не вносятся.

## 2026-10-08

### Отпуска и больничные

- Для сотрудников с рабочей неделей менее 40 часов рабочие дни отпуска и
  больничного в отчёте учитываются как 8 часов, предпраздничные — как 7 часов.
  В неполной неделе остальные дни сохраняют норму по личному графику.
  Праздники и выходные не добавляют часы отсутствия.

### Фильтры журналов

- Руководитель может выбирать период во всех списках уведомлений: работа вне
  офиса, опоздания, приостановки и ошибки учёта. Просмотр сотрудника сохраняет
  выбранные даты.
- Сотрудники могут выбирать период в личных журналах работы вне офиса,
  опозданий и приостановок. Даты для ручного ввода показываются только в режиме
  «Задать вручную»; подпись с фактическим периодом остаётся над таблицей.
- Просмотр ошибок учёта за прошлые кварталы не создаёт новые записи за
  закрытые периоды; действия по архивным ошибкам скрыты.

## 2026-10-07

### Опоздания

- Сотрудник и руководитель могут выбрать период журнала опозданий, включая
  предыдущий квартал и произвольный интервал. По умолчанию открыт текущий квартал.
- При просмотре конкретного сотрудника руководитель видит тот же период, который
  выбрал в общем списке. Счётчик открытых уведомлений от фильтра не зависит.

## 2026-10-05

### Учёт рабочего времени

- Незакрытые смены прошлых лет больше не отображаются как текущий рабочий день и
  не мешают новому приходу. Исторические записи остаются в базе для ручного
  исправления, но не могут создать приостановку через устаревшую сессию.

## 2026-09-09

### Тестовый стенд

- Добавлено ручное развёртывание выбранной проверенной ревизии на тестовый стенд
  через Gitea Actions. Перед переключением версии выполняются синтаксическая
  проверка PHP 8.4 и модульные тесты.
- При неудачном health-check тестовый стенд автоматически возвращается на
  предыдущую версию. Рабочий проект, рабочая база данных, Nginx и PHP-FPM
  сценарий не изменяет.

## 2026-08-21

### Учёт рабочего времени

- Исправлен учёт работы вне офиса: записи диапазона дней и интервалы, переходящие
  через полночь, распределяются по соответствующим датам без добавления лишних дней.
- Незавершённый рабочий день больше не создаёт продолжения приостановок или другой
  активности в следующих днях. Данные можно безопасно дозаполнить позднее.
- Для опозданий учитываются только официальные рабочие дни: выходные, отпуск,
  больничный и командировка не создают ложных опозданий.
- Причину опоздания можно внести сразу после регистрации позднего прихода; если
  окно закрыто без сохранения, действие остаётся доступным в журнале опозданий.

### Ошибки учёта и уведомления

- У сотрудников появилась индикация и счётчик ошибок учёта. Они обновляются после
  внесения данных, поэтому кнопка исчезает, когда все требуемые дни закрыты.
- Дни командировок без внесённой работы вне офиса выводятся отдельной таблицей в
  ошибках учёта сотрудника и руководителя. После внесения данных запись исчезает.
- Журналы работы вне офиса, опозданий и приостановок показывают период данных и
  не выводят битые записи с нулевым началом или окончанием.
- Решения руководителя по работе вне офиса и опозданиям обновляют список без
  ручной перезагрузки страницы.
- Ошибки учёта больше не формируются и не выводятся для неактуальных сотрудников
  с `RELEVANCE = 0`; при обновлении удаляются ранее накопленные служебные записи.

### Отсутствия и отчёты

- Выгрузка архива отсутствий в Excel учитывает выбранный период по фактически
  попавшим в него дням, содержит отчество, календарные и рабочие дни, а также
  рабочие часы.
- Временный отчёт получил подсказки к итоговым показателям и устойчивое отображение
  длинных значений времени.
- В архиве отсутствий добавлен корректный период «С начала года».

### Безопасность и поддержка

- Авторизация постепенно переводится с устаревшего MD5 на современные хеши PHP.
  При успешном входе старый пароль обновляется автоматически; прежние записи пока
  продолжают работать.
- Добавлен технический read-only отчёт по оставшимся MD5-учётным записям. Он
  показывает только агрегированные числа и не меняет данные сотрудников.
- Добавлены миграции БД и изолированные MySQL-интеграционные тесты для ключевых
  сценариев: рабочий день, приостановки, работа вне офиса, уведомления, командировки
  и сохранение авторизации.
- Настроены проверки Gitea Actions для PHP 8.4 и проверка совместимости с PHP 8.5.

## Правило добавления записи

Добавляйте новый раздел только для крупной функции, исправления, которое меняет
расчёты или данные, либо шага, необходимого при обновлении сервера. Указывайте
дату, короткий понятный заголовок и действие администратора, если оно требуется.
