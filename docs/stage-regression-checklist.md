# Чек-лист ручного тестирования стенда

Используйте этот список после переноса изменений на тестовый стенд. Проверяйте
сценарии минимум под двумя ролями: обычный сотрудник и руководитель. Не вносите
в этот документ пароли, токены, персональные комментарии или данные рабочей БД.

## Правила проверки

- Перед началом убедитесь, что `Optional stage smoke check` в Gitea завершилась
  успешно.
- Для каждого сценария фиксируйте результат: `пройдено`, `ошибка` или
  `не проверялось`.
- При ошибке сохраните URL страницы, действие, текст ошибки браузера и строки
  Nginx/PHP-лога за соответствующее время.
- Не проверяйте рискованные сценарии на реальных рабочих днях сотрудников без
  предварительного согласования. Используйте тестовые учётные записи.

## Сотрудник: вход и текущий день

| Сценарий | Ожидаемый результат | Результат |
|---|---|---|
| Вход с корректным логином и паролем | Открывается страница текущего дня, без ошибки `403` у AJAX. | |
| Обновление страницы после входа | Сессия сохраняется, повторный вход не требуется. | |
| Открытие страницы после короткого простоя | Сессия восстанавливается автоматически при действующем запомненном токене. | |
| Приход на работу | Время прихода и следующий набор кнопок появляются без долгого ожидания MySQL. | |
| Обед | После ухода на обед отображается окно/состояние обеда с корректной шириной. | |
| Возвращение с обеда | Кнопка ухода домой становится доступной только после фиксации возвращения. | |
| Уход домой | Рабочий день закрывается корректно, отчёт не получает лишних часов. | |
| Отмена действия обеда | Возврат к предыдущему состоянию обновляет панель регистрации. | |
| Приостановка времени | Открывается и завершается без отрицательной или чрезмерной длительности. | |
| Тренажёрный зал | Спортивная приостановка не мешает обычной приостановке и корректно завершается. | |

## Сотрудник: опоздания, работа вне офиса и ошибки учёта

| Сценарий | Ожидаемый результат | Результат |
|---|---|---|
| Поздний приход в рабочий день | Сразу открывается окно объяснения опоздания. | |
| Закрытие окна объяснения без сохранения | Кнопка внесения причины остаётся доступной. | |
| Сохранение объяснения | Запись появляется в журнале опозданий без HTML-тегов в комментарии. | |
| Приход в выходной, отпуск, больничный или командировку | Ложное опоздание не создаётся. | |
| Одна запись работы вне офиса | В журнале видны начало, окончание, длительность и комментарий. | |
| Диапазон работы вне офиса | Добавляются только выбранные дни, без лишних дат. | |
| Интервал через полночь | Часы распределяются между двумя датами без превышения суток. | |
| Фильтр работы вне офиса | Период из списка и ручной диапазон возвращают ожидаемые записи. | |
| Ошибка учёта | Счётчик на кнопке соответствует числу открытых записей. | |
| Данные по командировке | После внесения работы вне офиса напоминание по командировке и счётчик обновляются. | |

## Отчёты и отсутствия

| Сценарий | Ожидаемый результат | Результат |
|---|---|---|
| Личный временный отчёт | Таблица и итоги отображаются без `500`, размеры ячеек не расходятся. | |
| Отчёт с длинным периодом | Итоги не выходят за границы ячеек; подсказки и иконки понятны. | |
| Отсутствия сотрудников | Добавление, редактирование и удаление доступны только в актуальном разделе. | |
| Архив отсутствий | Фильтр и прокрутка работают, удаление исторической записи недоступно. | |
| Excel-выгрузка архива | Включает отчество, календарные/рабочие дни и часы только выбранного периода. | |
| Переработки | Поиск, период и таблица открываются без JavaScript-ошибок. | |

## Руководитель: уведомления

| Сценарий | Ожидаемый результат | Результат |
|---|---|---|
| Работа вне офиса | В списке все подчинённые отсортированы по фамилии, отображается период. | |
| Детали работы вне офиса | Открываются из уведомлений; кнопки любого меню остаются рабочими. | |
| Решение по работе вне офиса | Принятие, отклонение или удаление обновляют список без ручной перезагрузки. | |
| Опоздания | В списке все подчинённые, включая записи без объяснения; сортировка по фамилии. | |
| Детали опозданий | Открываются без `Access denied` и показывают историю сотрудника. | |
| Приостановки | Отображаются только завершённые корректные записи текущего квартала. | |
| Ошибки учёта | Обычные ошибки и напоминания о командировках выводятся отдельными таблицами. | |
| Кнопка «Назад» | Выравнивается по правой границе области данных, в том числе при пустом списке. | |

## Общая проверка интерфейса

| Сценарий | Ожидаемый результат | Результат |
|---|---|---|
| Основные страницы | Нет белого экрана с `0`, HTTP `500` и `403` при обычных действиях. | |
| Консоль браузера | Нет ошибок проекта; сообщения расширений браузера фиксировать отдельно. | |
| Таблицы и прокрутка | Голубой фон, таблицы, кнопки и вертикальные прокрутки не расходятся по краям. | |
| Навигация | Из любой детальной страницы можно перейти в любой основной раздел меню. | |
| Мобильное/узкое окно | Текст не перекрывается, нужные таблицы имеют прокрутку. | |
